# 綁定視窗與程序

「綁定」決定了按下快速鍵時**哪些視窗會被隱藏**。透過綁定多個目標，您可以一次隱藏所有涉及隱私的視窗，切換情境時不留遺漏。

開啟設定介面，切換到 **視窗綁定** 標籤頁。介面分為左右兩欄：

- **左欄（現有視窗）**：目前系統中存在的視窗清單。
- **右欄（已綁定規則）**：您已經新增的隱藏規則，分為「視窗隱藏」與「程序隱藏」兩組。

![ZoneDeck 視窗綁定頁](/static/screenshot-1.png)

## 視窗隱藏與程序隱藏

ZoneDeck 提供兩種粒度的綁定：

| 類型 | 粒度 | 說明 |
| --- | --- | --- |
| **視窗隱藏** | 細粒度 | 鎖定**單一視窗**（按視窗標題＋控制代碼智慧追蹤比對） |
| **程序隱藏** | 粗粒度 | 隱藏某個程式的**全部視窗**（按執行檔比對） |

::: tip 如何選擇

- 只想藏某個聊天視窗 → 用**視窗隱藏**。
- 想把某個程式（如某遊戲、某通訊軟體）的所有視窗都藏起來 → 用**程序隱藏**，即使新開視窗也會一併隱藏。
  :::

## 新增綁定

1. 在左側「現有視窗」清單中**勾選**一個或多個想隱藏的視窗。
2. 按一下右側對應清單的 **「新增」** 按鈕：
    - 新增到「視窗隱藏」→ 產生一條精確鎖定該視窗的規則。
    - 新增到「程序隱藏」→ 產生一條隱藏該程式全部視窗的規則。

若某個剛開啟的視窗沒有出現在左側清單中，按一下清單上方的 **「重新整理」** 按鈕即可。

## 篩選與搜尋現有視窗

現有視窗清單提供了篩選選項，協助您在眾多視窗中快速定位目標：

- **搜尋框**：按標題關鍵字篩選。
- **背景程序**：是否顯示目前不可見／背景的視窗。
- **無標題視窗**：是否顯示沒有標題的視窗。

## 刪除綁定

在右側規則清單中找到不再需要的規則，按一下其 **移除** 按鈕即可刪除。移除後該視窗將不再被一鍵隱藏。

## 進階：正規表示式比對

除了精確鎖定，ZoneDeck 還支援用**正規表示式**批次比對視窗標題或程序路徑，適合「標題會變化」或「想比對一類程式」的情境。

在視窗隱藏／程序隱藏清單上，按一下 **正規表示式** 按鈕會新建一條正規表示式規則，並以目前選取項目作為初始種子（方便修改）。

::: warning
正規表示式比對屬於進階模式，請確保您熟悉正規表示式語法，否則可能會出現比對不到或比對過多的情況。

若不熟悉正規表示式，請使用預設的精確比對。
:::

### 過寬提示

儲存時，ZoneDeck 會拿 **200 條隨機字串**去試每一條正規表示式。命中超過一半（100 條）就代表這條正則幾乎什麼都能比對上——`.*` 是最典型的例子，它會把所有視窗一併隱藏。

這時會彈出提示，輸入框也會標紅：

- 點 **仍然儲存**：確認這條正則就是你想要的，此後不再提醒，紅色標記消失。
- 點 **我知道了**：關掉提示但保留紅色標記，方便你回頭修改。

兩種選擇**都不會影響儲存**提示只是提醒。

### 視窗正規表示式規則

正規表示式作用於**視窗標題**。可額外設定：

- **比對無標題視窗**：是否把無標題視窗也納入比對（預設關閉，無標題視窗通常是不可見的）。
- **比對背景視窗**：是否把背景／不可見視窗也納入比對（預設關閉）。

例如，標題正規表示式 `^記事本.*` 可比對所有以「記事本」開頭的視窗。

預設情況下，按一下**正規表示式**按鈕會新增一條*包含*規則的正規表示式：

```regex
.*關鍵字.*
```

表示比對所有標題中包含「關鍵字」的視窗。您可以依需求修改正規表示式來實現更複雜的比對邏輯。

### 程序正規表示式規則

正規表示式預設作用於**執行檔完整路徑**。可額外設定：

- **比對檔名**：只按 `xxx.exe` 檔名比對，忽略所在的具體路徑。
- **比對無標題視窗**：是否把無標題視窗也納入比對（預設關閉，無標題視窗通常是不可見的）。
- **比對背景視窗**：是否把背景／不可見視窗也納入比對（預設關閉）。

例如，程序正規表示式 `.*\\LINE\.exe$` 可比對任意路徑下的 LINE 主程式。

::: warning 正規表示式撰寫注意
正規表示式中的反斜線 `\`、點號 `.` 等特殊字元需要正確逸出。路徑分隔符號在 Windows 上是反斜線，正規表示式裡通常寫作 `\\`。若規則未生效，請先檢查正規表示式是否正確。
:::
預設情況下，按一下**正規表示式**按鈕會新增一條*包含*規則的路徑比對正規表示式：

```regex
.*程式名稱\.exe.*
```
