# 快速上手

本章介紹 ZoneDeck 的基本操作：如何開啟設定、如何透過通知區域選單控制程式，以及預設快速鍵。

## 首次啟動

安裝或更新後**首次開啟** ZoneDeck 時，程式會自動開啟**設定介面**，方便您立即進行快速鍵修改、視窗／程序綁定等設定。

## 設定介面

| 標籤頁 | 內容 | 對應文件 |
| --- | --- | --- |
| **視窗綁定** | 選擇要隱藏的視窗／程序 | [綁定視窗與程序](/zh-tw/guide/binding) |
| **快速鍵與滑鼠** | 鍵盤快速鍵、滑鼠連按、四角手勢、閒置自動隱藏 | [快速鍵與滑鼠手勢](/zh-tw/guide/hotkeys) |
| **提示設定** | 控制氣泡通知與圖示狀態角標 | [提示設定](/zh-tw/guide/notifications) |
| **其他選項** | 靜音、暫停鍵、凍結、權限、記錄檔、復原工具等 | [其他選項](/zh-tw/guide/options) |
| **關於與意見回饋** | 版本資訊、檢查更新、公告、問題回報 | [檢查更新與意見回饋](/zh-tw/guide/update) |

::: tip 設定自動儲存
所有變更都會在您停止操作後**自動寫入磁碟並即時生效**，核心會在收到設定變更後**熱重新載入**，不需手動重新啟動。
:::

左側顯示核心的執行狀態，並依狀態提供相應的快捷操作。

**① 核心未執行** —— 核心未啟動，無法隱藏視窗。此時提供啟動按鈕：

- <Shield class="lucide-inline" style="color:#3b82f6" /> **以系統管理員啟動**：以系統管理員身分啟動核心（增強凍結等功能需要）。

<StatusBar variant="user" />

- <ScrollText class="lucide-inline" /> **開啟記錄檔資料夾**：開啟執行記錄所在的 `logs` 資料夾，便於排查問題。

## 通知區域選單

日常使用時，可以透過**以滑鼠右鍵按一下通知區域圖示**開啟選單。通知區域選單提供以下常用功能：

![ZoneDeck 核心通知區域選單](/static/screenshot-5.png)

- **設定**：開啟設定介面。
- **隱藏視窗／顯示視窗**：快速隱藏或顯示已綁定的視窗。
- **視窗復原工具**：開啟設定頁面並切換至視窗復原工具，參閱[視窗復原與當機防護](/zh-tw/guide/recovery)。
- **自動隱藏**：暫停／啟用[閒置自動隱藏](/zh-tw/guide/hotkeys#閒置自動隱藏)，勾選標記表示目前已啟用。
- **開機自動啟動**：切換是否隨系統登入自動啟動。
- **結束**：結束核心程序。

::: info 按一下通知區域圖示
若開啟了 [「按一下通知區域圖示切換隱藏」](/zh-tw/guide/options)，以左鍵按一下通知區域圖示即可快速隱藏／顯示視窗。
:::

## 預設快速鍵

ZoneDeck 預置了兩個鍵盤快速鍵，均可在 [快速鍵與滑鼠手勢](/zh-tw/guide/hotkeys) 中自訂：

| 功能 | 預設快速鍵 | 說明 |
| --- | --- | --- |
| **隱藏／顯示視窗** | `Ctrl + Q` | 按一次隱藏已綁定視窗，再按一次復原 |
| **關閉核心** | `Win + Esc` | 立即結束 ZoneDeck 核心程序 |

此外，全新安裝預設還開啟了**滑鼠中鍵連按兩下隱藏**，您可以在設定中調整或關閉。

## 基礎使用流程

1. 開啟設定介面 → **視窗綁定**，在左側選取要隱藏的視窗，按一下「新增視窗」綁定到右側。
2. （選用）在**快速鍵與滑鼠**中調整觸發方式。
3. 關閉設定介面，核心會在背景待命。
4. 需要隱藏時，按下隱藏快速鍵／觸發滑鼠手勢，綁定的視窗即刻消失並靜音。
5. 再次觸發即可復原。

接下來請閱讀 [綁定視窗與程序](/zh-tw/guide/binding)，瞭解如何精確地選擇隱藏目標。
