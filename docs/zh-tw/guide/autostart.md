# 開機自動啟動

開啟開機自動啟動後，ZoneDeck 核心會**隨系統登入自動在背景啟動**，您不需每次手動執行。

## 如何開啟／關閉

有兩種入口，效果一致：

1. **通知區域選單**：以滑鼠右鍵按一下通知區域圖示 → 選擇 **「開機自動啟動」** 切換狀態。
2. **設定介面**：**通用設定 → 啟動與權限 → 開機自動啟動** 開關。

切換後（若未關閉對應通知）會顯示通知提示目前的自動啟動狀態。開關旁的小字會標示目前的註冊方式（**排程工作** 或 **登錄檔**）。

## 自動啟動機制

ZoneDeck 採用**雙保險**的自動啟動方式，兼顧權限與可靠性：

| 機制 | 說明 |
| --- | --- |
| **排程工作（首選）** | 以「登入觸發」的排程工作註冊，可要求**最高權限**執行，並具備**失敗自動重新啟動** 能力 |
| **登錄檔啟動** | 當排程工作不可用時，將使用一般登錄檔啟動項目 |

設定介面「通用設定 → 啟動與權限 → 開機自動啟動」開關旁會以小字顯示目前實際生效的方式，便於您確認排程工作是否成功註冊（未成功時會回落到登錄檔）。

## 關於「最高權限自動啟動」

若您希望核心在開機時就**以系統管理員身分**啟動（例如為了 [增強凍結](/zh-tw/guide/freeze)），開啟 **啟動與權限 → 以系統管理員身分自動啟動** 開關即可——它會以最高權限的排程工作方式註冊自動啟動。

- 該開關**預設關閉**，即一般權限自動啟動，滿足絕大多數情境。
- 開關**僅在排程工作方式下生效**；若自動啟動回落到了登錄檔方式，則只能以一般權限啟動。
- 在自動啟動已開啟時切換該開關，會立即按新權限**重新註冊**，不需手動關閉再開啟。

::: warning 解除安裝／搬移前請先關閉自動啟動
如果您要刪除可攜版資料夾或搬移程式位置，請**先在通知區域選單關閉開機自動啟動**，以免殘留一個指向舊路徑的失效自動啟動項目。
:::
