# 其他選項

設定介面的 **其他選項** 標籤頁集中了隱藏行為的增強開關、啟動權限、記錄檔與工具。本頁介紹其中的一般選項、執行權限與記錄檔。程序凍結與記憶體清理請參閱[程序凍結](/zh-tw/guide/freeze)（設定位於 **能效控制** 標籤頁），視窗復原工具請參閱[視窗復原與當機自癒](/zh-tw/guide/recovery)。

![ZoneDeck 其他選項頁](/static/screenshot-4.png)

## 一般

### 隱藏視窗後靜音

隱藏視窗時**將目標程序的音訊靜音**，復原顯示時自動取消靜音。適合在隱藏正在播放聲音的影片／音樂視窗時使用。

- 預設**開啟**。
- 基於 Windows Core Audio 工作階段層級靜音，僅靜音目標程序，不影響系統其他聲音。

### 同時隱藏目前使用中的視窗

開啟後，按下隱藏快速鍵時，除已綁定的視窗外，還會**同時隱藏目前正在作用中的前景視窗**。

- 預設**開啟**。
- 適合「暫時正在看的視窗沒有事先綁定」的情境。

### 按一下通知區域圖示切換隱藏

開啟後，**以左鍵按一下通知區域圖示**即可隱藏／顯示視窗。

- 預設**開啟**。

### 一併隱藏 ZoneDeck 通知區域圖示

開啟後，隱藏視窗時會**連 ZoneDeck 自身的通知區域圖示一起隱藏**，更加隱密；再次觸發復原即可復原視窗與圖示。

- 預設**關閉**。
- 該選項只作用於 ZoneDeck 自己的通知區域圖示，**不會隱藏其他程式的通知區域圖示**（包括被隱藏視窗所屬程式的圖示）。

::: warning
通知區域圖示被隱藏後，您將無法透過按圖示來復原或開啟設定。請務必記住您的**隱藏／顯示快速鍵**或滑鼠手勢，用它來復原。
:::

::: tip 隱藏其他程式的通知區域圖示
Windows 內建控制通知區域圖示顯示與否的功能，可手動設定哪些程式的圖示顯示在工作列角落，詳細步驟參見微軟官方教學 [在 Windows 中自訂工作列 · 系統匣](https://support.microsoft.com/zh-tw/windows/experience/personalization/customize-the-taskbar-in-windows#system-tray)，或直接開啟 [工作列設定](ms-settings:taskbar)（`ms-settings:taskbar` 連結僅在 Windows 上有效，瀏覽器會先要求確認）。
:::

### 隱藏前傳送暫停鍵

開啟後，隱藏視窗**前**會先向視窗傳送**媒體暫停鍵**，嘗試暫停其中正在播放的影片／音樂。

- 預設**關閉**。
- 與「隱藏後靜音」側重點不同：靜音只是消音，暫停鍵會真正暫停播放。
- 除了此功能外，ZoneDeck 提供的**程序凍結**功能，也有相同的暫停效果，同時還能降低資源消耗，詳見 [程序凍結](/zh-tw/guide/freeze)。

### 隱藏前先最小化視窗

開啟後，隱藏視窗**前**會先把它**最小化**，復原時再還原成隱藏前的大小。

- 預設**關閉**。
- 隱藏前是**最大化**的視窗，復原後仍是最大化，不會被還原成一般大小。
- 隱藏前**就已最小化**的視窗保持最小化——ZoneDeck 沒有替你最小化它，復原時自然也不替你還原。
- 某些程式在收到最小化訊息時會釋放一部分資源（如暫停算圖、收合到通知區），搭配[程序凍結](/zh-tw/guide/freeze)使用效果更明顯。

::: tip 隱藏與復原是一次成對的切換
ZoneDeck 的「復原」只逆轉**它自己造成的**改變：沒被它最小化的視窗不會被還原大小，沒被它隱藏的視窗（程式自己藏起來的）也不會被彈出來。但靜音、凍結這類副作用仍會照常施加與撤銷。
:::

## 啟動與權限

### 開機自動啟動

切換 ZoneDeck 是否隨系統登入自動啟動核心。詳細機制見 [開機自動啟動](/zh-tw/guide/autostart)。

### 核心執行權限

顯示目前核心的執行狀態（未執行／一般使用者／系統管理員），並提供**以系統管理員身分啟動／重新啟動核心**的按鈕。

以下功能需要核心以系統管理員身分執行：

- [增強凍結](/zh-tw/guide/freeze)；
- [排程工作最高權限自動啟動](/zh-tw/guide/autostart)。

## 語言

### 介面語言

設定設定介面與核心的通知區域選單、通知所使用的語言。

可選值：**跟隨系統／简体中文／English／繁體中文**，預設 **跟隨系統**。

- 選擇「跟隨系統」時，依 Windows 的顯示語言決定：中文（台灣／香港／澳門）顯示繁體中文，其他中文顯示簡體中文，英文顯示英文，其餘語言回落到簡體中文。
- 變更即時生效，設定介面與核心同時切換，不需重新啟動。
- 執行記錄不受該設定影響，一律以簡體中文記錄。

## 記錄檔

### 記錄檔保留天數

核心執行記錄按日儲存在**程式資料夾的 `logs` 資料夾**內，核心啟動時會自動清除更早的記錄檔。

可選值：**關閉／3 天／7 天／14 天／30 天**，預設 **7 天**。選擇「關閉」則完全不記錄。

### 記錄輸出等級

只記錄所選等級**及以上**的內容。可選值：**偵錯／資訊／警告／錯誤**，預設 **警告**。

| 等級 | 記錄範圍 |
| --- | --- |
| 偵錯 | 全部內容，含每次隱藏／還原的明細、熱鍵註冊結果等流水 |
| 資訊 | 上述流水之外的執行里程碑，如更新後首次啟動 |
| 警告（預設） | 只記警告與錯誤：熱鍵註冊失敗、規則未比對到視窗、偵測到上次異常結束等 |
| 錯誤 | 只記錯誤：核心無法啟動、設定解析失敗、當機資訊等 |

預設的「警告」下，日常的隱藏與還原**不會寫進記錄檔**，只留下真正需要關注的內容。回報問題前可暫時調低到「偵錯」，重現一次問題後再調回。「記錄檔保留天數」選擇關閉時此項無法使用。

無論選哪一級，每次啟動與正常結束都會各記一行工作階段標記，其中含版本號與資料目錄，便於定位問題。

::: tip 排查問題先看記錄檔
當程式出現異常時，`logs` 資料夾中的記錄檔是定位問題的第一手資料。回報問題時附上相關記錄檔能大幅提高排查效率。相關內容另見 [視窗復原與當機自癒](/zh-tw/guide/recovery)。
:::

## 工具

### 視窗復原工具

用於**找回被誤隱藏、無法透過快速鍵復原的視窗**。按一下「開啟」後會列出所有視窗，勾選後即可復原顯示。詳見 [視窗復原與當機自癒](/zh-tw/guide/recovery)。
