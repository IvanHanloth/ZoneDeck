# 提示設定

ZoneDeck 透過**系統通知**與**圖示角標**兩類提示反映核心狀態。在設定介面的 **一般設定** 標籤頁，您可以決定通知區域圖示是否顯示、按下它做什麼，以及各類通知與角標的行為，做到既知情又不打擾。

## 顯示通知區域圖示

通知區域圖示預設顯示在通知區域。關閉該選項後圖示完全消失，更為隱密。

- 預設**開啟**。
- 圖示關閉後，圖示上的點擊行為、懸浮名稱與狀態角標隨之失效，設定介面中對應的設定項會變灰。**通知不受影響**，照常顯示。
- **一併隱藏 ZoneDeck 通知區域圖示**（[隱藏設定](/zh-tw/guide/hiding#一併隱藏-zonedeck-通知區域圖示)）是隱藏視窗時的連動，與本項相互獨立。
- 此開關變更後立即生效，不必重新啟動核心。

::: warning 關閉之前先想好怎麼找回來
沒有圖示就按不到選單。此時仍可**再次執行 ZoneDeck**（連按兩下程式或捷徑）開啟設定介面 —— 核心已在執行時，重複啟動會轉為開啟設定。但復原視窗只能靠您的**隱藏／顯示快速鍵**或滑鼠手勢，請務必先記住它。
:::

## 通知區域圖示點擊行為

通知區域圖示的**左鍵按一下**、**左鍵按兩下**、**右鍵按一下**各自繫結一個動作，可選：

| 動作 | 說明 |
| --- | --- |
| **不做任何事** | 什麼都不做 |
| **隱藏／顯示視窗** | 切換隱藏狀態，等同按一次隱藏／顯示快速鍵 |
| **顯示通知區域選單** | 顯示[通知區域選單](/zh-tw/guide/getting-started#通知區域選單) |
| **開啟設定介面** | 開啟本設定視窗 |

預設繫結：

| 點擊 | 預設動作 |
| --- | --- |
| 左鍵按一下 | 隱藏／顯示視窗 |
| 左鍵按兩下 | 不做任何事 |
| 右鍵按一下 | 顯示通知區域選單 |

::: tip 按兩下一旦綁上，按一下就會慢半拍
系統無法在第一次按下時就斷定後面還有沒有第二下。因此只要按兩下綁了動作，按一下就必須等過系統的連按判定時間（可在 Windows 滑鼠設定裡調整）才能執行。按兩下保持「不做任何事」時沒有這個衝突，按一下立即回應。
:::

## 可控制的通知事件

| 事件 | 說明 | 預設 |
| --- | --- | :---: |
| **核心啟動** | 核心開始執行時提示 | 開啟 |
| **核心結束** | 核心結束時提示 | 開啟 |
| **開機自動啟動狀態變更** | 切換開機自動啟動時提示目前狀態 | 開啟 |
| **隱藏視窗** | 每次隱藏視窗時提示 | 關閉 |
| **顯示視窗** | 每次顯示視窗時提示 | 關閉 |

## 圖示狀態提示

通知區域圖示可在**右下角疊加一個彩色圓點角標**，直觀反映核心目前狀態。四種顏色各自繫結一個狀態來源，預設繫結如下：

| 顏色 | 預設繫結狀態 |
| --- | --- |
| 紅色 | 存在隱藏中的視窗 |
| 綠色 | 已啟用自動隱藏 |
| 黃色 | 已啟用同時隱藏目前視窗 |
| 藍色 | 已啟用程序凍結 |

- 每種顏色都可以改繫結為其他狀態（除上表四種外，還可繫結**以系統管理員身分執行**、**快速鍵監控已暫停**），或選擇「不顯示」停用該顏色。
- 多個繫結狀態同時滿足時，依 **紅 > 綠 > 黃 > 藍** 的優先順序僅顯示一個圓點。

::: warning 隱密性提示
角標（尤其是「存在隱藏中的視窗」）也會向旁人透露核心狀態。若您更在意隱密性，可停用相應顏色。
:::

## 顯示圖示懸浮名稱

滑鼠停留在通知區域圖示上時預設顯示「ZoneDeck」。關閉該選項後，停留不顯示任何文字，更為隱密。

- 預設**開啟**。

## 使用建議

- **隱藏／顯示通知預設關閉**：隱藏本身就是為了保護隱私，每次隱藏都顯示通知反而會引起注意，因此預設不提示。若您希望有明確回饋可自行開啟。
- **啟動／結束／自動啟動通知預設開啟**：這些是低頻事件，保留提示有助於您確認核心狀態。

::: info 與「隱藏 ZoneDeck 通知區域圖示」的區別
[一併隱藏 ZoneDeck 通知區域圖示](/zh-tw/guide/hiding#一併隱藏-zonedeck-通知區域圖示) 是**隱藏視窗時**的連動，觸發復原會復原顯示；本頁的「顯示通知區域圖示」則是使通知區域圖示**一直不顯示**。
:::
