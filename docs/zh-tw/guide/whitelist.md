# 白名單

你可以為 ZoneDeck 設定程序白名單，使其對特定程序的視窗略過特定步驟。

隱藏視窗時，ZoneDeck 可能對目標做三件事——隱藏視窗、凍結程序、靜音音訊。白名單讓你逐個程式、逐項關掉其中任意一件，其餘照舊。

開啟設定介面，切換到 **白名單** 標籤頁。介面與[視窗綁定](/zh-tw/guide/binding)同構：左欄是現有視窗，右欄是白名單項目。

## 三種略過模式

每條白名單項目上有三個獨立開關，互不影響：

| 開關 | 作用 |
| --- | --- |
| **略過隱藏** | 隱藏時跳過這個程式的視窗，它始終留在桌面上 |
| **略過凍結** | 不[凍結](/zh-tw/guide/freeze)它的程序，背景工作繼續跑 |
| **略過靜音** | 不靜音這個程式 |

三個開關**相互獨立**。凍結與靜音是否觸發是根據「這個程式還有沒有視窗留在桌面上」——視窗開著就都不會施加，而它自己縮到通知區後照樣會被凍結、靜音。

## 新增項目

1. 在左側「現有視窗」清單中**勾選**目標視窗。
2. 點選右側的 **新增程序** 按鈕。
3. 在新增的那一列上勾選需要的略過模式（新項目預設三個都不勾，等同於沒有效果）。

## 比對依據

與[程序隱藏規則](/zh-tw/guide/binding)一樣，每條項目可以選擇按**檔名**或按**路徑**比對：

- **檔名**（預設）：只看 `xxx.exe`，程式裝在哪個資料夾都算命中。白名單預設按檔名比對——換個安裝資料夾就失效的保護形同虛設。
- **路徑**：只放過指定位置的那一個程式，同名的其他副本不受影響。

點選 **正則** 按鈕可以新增正規表示式項目，正則作用於檔名還是完整路徑同樣由「比對依據」決定。

::: tip
檔名與路徑的比較都**不區分大小寫**：`Explorer.EXE` 與 `explorer.exe` 是同一個目標。
:::

## 預設項目：檔案總管

全新安裝時，白名單裡預置了一條 `explorer.exe`，勾選了**略過隱藏**與**略過凍結**。

檔案總管就是桌面與工作列本身：隱藏它會讓桌面圖示一併消失，凍結它會讓整個 Windows 殼層卡住。這條是普通項目，你可以修改或刪除它。

## 內建項目：ZoneDeck 自己

清單最上方有兩條帶鎖的項目，**不能修改也不能刪除**：

| 項目 | 涵蓋的映像名 |
| --- | --- |
| ZoneDeck 核心 | `ZoneDeck.exe`、`core.exe` |
| ZoneDeck 設定 | `config.exe`、`zonedeck-config.exe` |

它們恆定處於「略過凍結」狀態。原因是這樣的：核心通常由檔案總管啟動，因而是 `explorer.exe` 的子程序；設定程式又是核心的子程序。一旦你把[作用範圍](/zh-tw/guide/freeze#作用範圍)設成「目標程序及所有子程序」去凍結檔案總管，整棵程序樹連 ZoneDeck 一起被暫停——快速鍵不再回應，設定介面開不了，已經隱藏的視窗**再也無法復原**。

[視窗復原工具](/zh-tw/guide/recovery)裡的手動凍結同樣受它保護。

## 與隱藏規則的關係

白名單的優先權**高於**[視窗綁定](/zh-tw/guide/binding)裡的任何規則。一個程式既被程序隱藏規則命中、又在白名單裡勾了「略過隱藏」時，白名單說了算——規則不必刪掉，臨時不想讓它參與隱藏，勾一下白名單即可。
