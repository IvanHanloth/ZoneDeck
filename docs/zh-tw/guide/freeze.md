# 程序凍結

**程序凍結** 是隱藏視窗後的一項增強功能：在隱藏視窗的同時「暫停」對應的程序，使其停止佔用 CPU（例如暫停背景影片解碼、遊戲算圖等）；復原顯示時自動解除凍結。

相關設定位於設定介面的 **能效控制** 標籤頁。

::: warning 程序凍結為進階功能
凍結會讓目標程序完全停止執行，其背景工作（如下載、訊息接收）也會暫停。請在瞭解影響後再啟用。
:::

::: info 凍結不會降低記憶體佔用
暫停只是讓程序的執行緒不再被排程，它**完全不觸碰記憶體管理員**——已經佔著的實體記憶體一頁都不會還回去，工作管理員裡的「記憶體」一欄紋風不動。想讓記憶體也降下來，見下文的[降低記憶體佔用](#降低記憶體佔用)。
:::

## 隱藏視窗時凍結程序

這是凍結功能的**總開關**。開啟後，每次隱藏命中的視窗時，ZoneDeck 會暫停對應程序；復原顯示時自動解除凍結，預設使用一般凍結，**不需系統管理員權限**即可對目前使用者的程序生效。

暫停與解除凍結本身需要時間，開啟後可能會造成一定的隱藏／復原延遲。

## 使用增強凍結

一般凍結對某些複雜程式（多程序架構、有算圖子程序等）可能不夠徹底。**增強凍結**改用微軟官方的 `pssuspend64.exe` 工具來暫停程序，效果更強。

啟用增強凍結需要**同時滿足**以下前置條件，否則該選項會被停用：

1. 已開啟「隱藏視窗時凍結程序」總開關；
2. **核心以系統管理員身分執行**（見下文與 [其他選項](/zh-tw/guide/options)）；
3. 程式資料夾下存在 **`pssuspend64.exe`** 檔案。

### 如何取得 pssuspend64.exe

1. 前往微軟 Sysinternals 的 [PSTools 下載頁](https://download.sysinternals.com/files/PSTools.zip)。
2. 解壓縮下載取得的 `PSTools.zip`。
3. 從中找到 **`pssuspend64.exe`**，複製到 ZoneDeck 的**程式安裝根資料夾**。
4. 回到設定介面，按一下「程序凍結」區域的 **重新偵測** 按鈕，讓 ZoneDeck 辨識到該檔案。

增強凍結需呼叫外部程式，同樣會造成一定的隱藏／復原延遲。

## 作用範圍

**作用範圍**決定凍結與[降低記憶體佔用](#降低記憶體佔用)涵蓋到哪些程序——兩者共用同一個範圍，不必分別設定。預設只管命中視窗所屬的程序本身。

| 取值 | 涵蓋 | 適合 |
| --- | --- | --- |
| **僅目標程序** | 命中視窗所屬的程序 | 預設。單程序程式，或只想動主程序 |
| **目標程序及所有子程序** | 上者 ∪ 它的全部後代 | 瀏覽器、Electron 應用這類有算圖／輔助子程序的程式 |
| **同一程式的所有實例** | 系統裡所有**同映像名稱**的程序 | 多開的同一個程式 |

::: tip 「同一程式的所有實例」按檔名比對
它認的是映像名稱（如 `chrome.exe`），不看程序之間的親緣關係，也不區分安裝資料夾——兩個不同位置的同名程式會被一起納入。它**不含**不同名的子程序，那要靠「目標程序及所有子程序」。
:::

::: warning
範圍越大效果越徹底，也越可能影響到你沒打算動的背景工作，並造成更高的隱藏／復原延遲。「目標程序及所有子程序」仍在測試階段。
:::

::: danger 別凍結檔案總管
`explorer.exe` 就是桌面與工作列本身，凍結它會讓整個 Windows 殼層卡住。而且 ZoneDeck 通常由它啟動、是它的子程序——用「目標程序及所有子程序」凍結檔案總管會把 ZoneDeck 一起暫停。

因此 ZoneDeck 的核心與設定程式被**內建**在[白名單](/zh-tw/guide/whitelist)裡，恆不凍結、不可關閉；`explorer.exe` 也預置了一條可刪除的白名單項目。
:::

## 排除特定程式

不想凍結某個程式時，把它加進[白名單](/zh-tw/guide/whitelist)並勾上「略過凍結」即可，不必關掉總開關。

## 降低記憶體佔用

凍結本身不省記憶體。開啟 **降低記憶體佔用** 後，ZoneDeck 會在凍結成功之後**清空該程序的工作集**，把它常駐在實體記憶體裡的資料挪到分頁檔，工作管理員的「記憶體」一欄會立刻回落。

::: warning
該選項仍在測試階段。**可能延長復原所需時間，但能一定程度上節省記憶體**——復原時這些資料要從分頁檔讀回來，程序越大、機械硬碟越慢，卡頓越明顯。請在瞭解影響後再啟用。
:::

- 預設**關閉**，且需要先開啟「隱藏視窗時凍結程序」，否則該選項會被灰化。
- 只對**被凍結的**程序生效，涵蓋範圍與凍結一致（見[作用範圍](#作用範圍)）。還在執行的程序會立刻把資料讀回來，清了也白清。
- 省下的記憶體有一部分是帳面上的：清出去的資料會先進入系統的待命清單，本來在記憶體吃緊時系統也會自己回收。這個選項只是把這筆開銷提前付了。

### 為什麼凍結不會降低記憶體

暫停程序走的是 `NtSuspendProcess`，它做的事只有一件：讓程序裡所有執行緒不再被排程。程序的虛擬位址空間、已認可的記憶體、工作集全部原樣保留——暫停是**排程**層面的操作，和記憶體管理毫不相干。

而 Windows 只在兩種情況下才會把實體記憶體收回去：系統記憶體吃緊時由記憶體管理員主動修剪，或者有人明確要求清空某個程序的工作集。凍結既不製造記憶體壓力，也不會觸發修剪，所以在記憶體充裕的機器上，被凍結的程序能原樣揣著幾百 MB 不放。「降低記憶體佔用」做的就是那個明確要求。

## 當機安全

ZoneDeck 會把目前凍結了哪些程序記錄到 `recovery.json`。即使核心異常結束，重新啟動後也會**自動解除凍結**先前被暫停的程序。

前往 [視窗復原與當機自癒](/zh-tw/guide/recovery) 瞭解如何手動復原被凍結的程序。
