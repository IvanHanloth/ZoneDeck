# Boss Key 使用說明

**Boss Key（老闆鍵）** 是一款針對 Windows 平台的「摸魚」輔助工具：當您需要快速隱藏正在使用的視窗時，只需按下一個快速鍵、按一下滑鼠，或將滑鼠甩到螢幕角落，即可一鍵隱藏並靜音指定視窗；老闆走後再觸發一次即可復原。

![Boss Key 設定介面 - 視窗綁定頁](/static/screenshot-1.png)

## 主要特性

- **多視窗／多程序隱藏**：可同時隱藏任意數量的視窗，或按程序隱藏某個程式的全部視窗。
- **多種觸發方式**：鍵盤全域快速鍵、滑鼠中鍵／側鍵連按（可搭配輔助按鍵）、快速移動到螢幕四角、閒置自動隱藏。
- **隱藏增強**：隱藏後自動靜音、傳送媒體暫停鍵、凍結程序以降低 CPU／記憶體佔用、連通知區域圖示一起隱藏。
- **精細比對**：既能鎖定單一視窗，也能用**正規表示式**批次比對標題或程序路徑。
- **極低佔用**：v3 以 Rust 重寫，核心常駐僅約 350 KB 二進位檔、約 1 MB 記憶體。
- **穩定可靠**：當機記錄、當機復原、監控程式三層防線，避免視窗「永久消失」。
- **現代設定介面**：無邊框視窗、淺色／深色／跟隨系統佈景主題、設定自動儲存、內建檢查更新與意見回饋。

## 系統需求

| 項目 | 需求 |
| --- | --- |
| 作業系統 | Windows 10 以上（部分版本另提供 Windows 7 軟體包） |
| 執行階段相依性 | 設定介面相依於系統內建的 Microsoft Edge **WebView2**（Win10/11 通常已內建） |
| 權限 | 預設一般使用者權限即可執行；僅**增強凍結**與**排程工作最高權限自動啟動**需要系統管理員 |

## 版本說明

::: info v3 全新重構
自 **v3.0.0** 起，Boss Key 以 **Rust + Tauri** 全面重寫，相較於早期的 Python 版本大幅降低了記憶體佔用、提升了穩定性，並採用了全新的視覺設計。本使用說明以 v3 為準。
:::
