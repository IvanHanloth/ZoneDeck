# 檢查更新與意見回饋

設定介面的 **關於與意見回饋** 標籤頁匯集了版本資訊、檢查更新、公告與問題回報功能。

## 檢查更新

開啟方式有兩種：

1. **通知區域選單** → 「關於」。
2. **設定介面** → 關於與意見回饋頁。

檢查更新會自動嘗試從伺服器取得最新版本資訊與下載網址：

- 若有新版本，會顯示版本號與更新說明，按一下即可前往下載。
- 設定介面也會在啟動時**自動**進行一次更新檢查。

### 包含預覽版

預設只檢查**穩定版**。若您希望第一時間體驗尚未正式發布的功能，可開啟「接收預覽版」，讓更新檢查也納入預先發行（如 `-rc`）版本。

::: warning
預覽版可能包含未完全測試的功能，穩定性不如正式版，請謹慎使用。
:::

## 公告

Boss Key 支援顯示來自伺服器的**公告**（如重要更新提示、已知問題說明等）。有新公告時會自動顯示；已讀過的公告不會重複打擾。

## 問題回報

在「關於與意見回饋」頁可以直接提出**意見回饋／問題回報**，也可以透過 **GitHub 儲存庫** 提交 [Issue](https://github.com/IvanHanloth/Boss-Key/issues)。

::: tip 回報時請附上資訊
為便於定位問題，回報時建議附上：
- Boss Key 版本號；
- 作業系統版本；
- 重現步驟；
- 相關的 [記錄檔](/zh-tw/guide/options)。
:::

您也可以直接前往 GitHub 儲存庫提交 [Issue](https://github.com/IvanHanloth/Boss-Key/issues)。儲存庫提供了 **Bug 回報** 與 **功能建議** 兩種 Issue 範本，按範本填寫能讓維護者更快理解您的問題，**這是更建議的做法**。
