# 檢查更新與意見回饋

設定介面的 **關於與意見回饋** 標籤頁匯集了版本資訊、檢查更新、公告與問題回報功能。

## 檢查更新

開啟方式有兩種：

1. **通知區域選單** → 「關於」。
2. **設定介面** → 關於與意見回饋頁。

檢查更新會自動嘗試從伺服器取得最新版本資訊與下載網址：

- 若有新版本，會顯示版本號與更新說明，按一下即可前往下載。
- 設定介面也會在啟動時**自動**進行一次更新檢查。

### 包含預覽版

預設只檢查**穩定版**。若您希望第一時間體驗尚未正式發布的功能，可開啟「接收預覽版」，讓更新檢查也納入預先發行（如 `-rc`）版本。

::: warning
預覽版可能包含未完全測試的功能，穩定性不如正式版，請謹慎使用。
:::

## 公告

ZoneDeck 支援顯示來自伺服器的**公告**（如重要更新提示、已知問題說明等）。有新公告時會自動顯示；已讀過的公告不會重複打擾。

## 公告與更新說明的語言

公告與更新說明會依**目前的介面語言**取得：切換介面語言後會立刻依新語言重新取一次。某則內容沒有對應語言的版本時，顯示其預設語言的原文。

## 問題回報

在「關於與意見回饋」頁可以直接提出**意見回饋／問題回報**，也可以透過 **GitHub 儲存庫** 提交 [Issue](https://github.com/IvanHanloth/ZoneDeck/issues)。

::: tip 回報時請附上資訊
為便於定位問題，回報時建議附上：
- ZoneDeck 版本號；
- 作業系統版本；
- 重現步驟；
- 相關的 [記錄檔](/zh-tw/guide/options)。
:::

::: warning 請留下聯絡方式
如果不留聯絡方式，我們無法直接回覆與處理這則意見。因此關於功能請求以及 bug 之類的問題，仍建議將其轉換為 Issue。
:::

### 同時轉換為 GitHub Issue

意見回饋框下方提供 **同時轉換為 GitHub Issue** 選項（由伺服器決定是否開放，未開放時不顯示）。勾選後送出，這則意見回饋會由 Verhub 機器人自動轉換為 GitHub Issue：

- **不需要特別的網路環境**，也**不需要登入 GitHub 帳號**；
- 選擇轉換時聯絡方式**為必填，且應填 GitHub 帳號**（形如 `@IvanHanloth`）——機器人建立 Issue 後，後續追蹤要靠它找到您；
- Issue 建立失敗時整則意見回饋不會被記錄，此時請改用下方的手動方式。

您也可以直接前往 GitHub 儲存庫提交 [Issue](https://github.com/IvanHanloth/ZoneDeck/issues)。儲存庫提供了 **Bug 回報** 與 **功能建議** 兩種 Issue 範本，按範本填寫能讓維護者更快理解您的問題。
