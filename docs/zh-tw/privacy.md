# ZoneDeck 隱私權聲明

**生效日期：2026 年 9 月 20 日** | **最後更新：2026 年 9 月 20 日**

你的隱私對我們至關重要。本隱私權聲明說明了 ZoneDeck（以下簡稱「本程式」）處理的資料、處理方法以及用途。本程式由個人開發者 *
*Ivan Hanloth** （以下簡稱「我們」）開發與維護。請完整閱讀本聲明，特別是以**粗體**標示的條款。如果你不同意本聲明的條款，請停止使用本程式。若你是未滿
14 歲的未成年人，請在監護人的指導下閱讀本聲明，並在取得監護人同意後再使用需要連網的功能。

### 我們收集和處理的資料

本程式透過你與我們的互動以及你對本程式的使用來收集或處理有限的資料。我們處理的資料類型取決於你使用的功能以及你所做的隱私設定。

**1. 僅在你的裝置上進行本機處理的資料** 為提供視窗管理、程序凍結等核心功能，本程式會在你的裝置本機（`%APPDATA%\ZoneDeck`
或可攜版所在資料夾）產生和讀取以下資料。**這些資料不會被上傳至任何伺服器：**

* **設定檔（`config.json`）與復原資料（`recovery.json`）**
  ：包括你設定的視窗規則（視窗控制代碼、程序名稱、正規表示式等）、程序和白名單規則、快速鍵與滑鼠綁定、介面偏好，以及用於程式意外結束時找回視窗的狀態紀錄。

* **執行記錄（`logs\`）與節能統計（`stats.json`）**：按日記錄的執行記錄（在寫入磁碟前已統一去識別化，不含視窗標題、使用者資料夾等敏感資訊），以及供顯示用的凍結時長、釋放記憶體等節能成績。

* **系統互動與權限資料（僅在記憶體中處理）**：本程式會列舉目前的視窗與程序資訊。當你啟用相應的快速鍵時，會安裝 Windows
  低階鍵盤／滑鼠掛鉤（`WH_KEYBOARD_LL` / `WH_MOUSE_LL`）。我們承諾，**這些掛鉤僅用於比對快速鍵或即時判定手勢，絕不具備鍵盤側錄功能，不儲存、不傳送你的按鍵內容或滑鼠軌跡。
  **

**2. 會離開你裝置的資料**
我們收集和傳送的資料包括：

* **必需的裝置和執行資料**：為提供檢查更新和取得公告服務，程式會在開啟設定頁面時自動向伺服器傳送有限的資料（專案識別碼、平台類型、系統版本、應用程式版本號、介面語言）。
  **這不含任何可識別你身分的資訊。**

* **診斷和使用情況資料**：預設關閉，僅當你主動選擇「同意參與」後，我們才會收集匿名的使用統計，其包含各項功能的啟用狀態、規則數量統計和一組隨機產生的匿名識別碼。

* **錯誤回報和意見回饋**：
    * **錯誤記錄**：程式出錯時顯示的故障記錄，用於問題追溯，**僅在你點擊「回報給開發者」之後才會傳送**。

    * **使用者意見回饋**：你在「關於與意見回饋」頁面主動填寫的內容、評分和選填的聯絡方式。

### 我們絕不收集的資料

在任何情況下本程式不會主動讀取、記錄或傳送以下資訊：

* 鍵盤資訊、剪貼簿內容、螢幕內容或螢幕擷取畫面。

* 視窗標題、程序名稱、檔案路徑、正規表示式。

* 你的姓名、電子郵件、電話等身分資訊。

* 裝置唯一實體識別碼（如 MAC 位址、序號、廣告識別碼）、地理位置、感測器資料。

* 本機安裝的其他軟體清單、瀏覽紀錄或帳號密碼等身分憑證。

本程式不投放廣告，不進行商業化使用者剖析，不進行跨應用程式追蹤，不出售、出租或交換任何資訊。

### 我們如何使用資料

具體而言，我們使用上述收集到的有限資料來實現以下目的：

* **提供和維護我們的產品**：我們在本機使用你的設定資料來執行你要求的視窗隱藏、程序暫停等核心操作。我們使用基礎裝置資料為你提供軟體更新和最新公告。

* **產品改進和開發**：如果你選擇參與匿名使用統計，我們會利用這些資料分析各項功能的受歡迎程度，以便做出明智的決策，持續最佳化產品設計。

* **客戶支援和疑難排解**：當你主動向我們傳送錯誤回報或意見回饋時，我們會使用這些資訊來排查故障、修復缺陷、保障服務安全，並在你留下聯絡方式時對你的問題進行回覆。

### 我們共享資料的原因

一般情況下，我們不會與第三方共享你的資料。但為了提供更新、統計和意見回饋等服務，我們會使用受信任的第三方，或在特定情況下進行揭露：

* **Verhub**：本程式的檢查更新、統計、錯誤和意見回饋接收均由 Verhub 服務（`https://verhub.hanloth.cn`）提供與處理。這些網路請求不可避免地會產生
  IP 位址和存取記錄。詳細的資料處理規則適用 [Verhub 隱私權政策](https://verhub.hanloth.cn/terms/privacy-policy)。

* **GitHub（當你主動選擇時）**：如果你在送出意見回饋時勾選「同時轉換為 GitHub Issue」，你的回饋內容和聯絡方式將經由 Verhub
  被自動發布到 ZoneDeck 的 GitHub 儲存庫中，**此內容將對所有人公開可見**。請在勾選前審慎評估，避免在其中包含個人隱私。

* **合法性與安全性**：如果為了遵守適用法律，或為了保護開發者及使用者的權利、財產與安全，我們可能會處理或保留有限的資料。

### 如何存取和控制你的資料

你對自己的資料擁有絕對的控制權，可以隨時透過以下方式進行管理：

* **存取、修改和刪除本機資料**：你可以隨時透過系統的檔案總管直接檢視、修改或刪除本機上的設定檔和記錄檔。在解除安裝本程式時，選擇「不保留設定」即可徹底清除所有本機資料。

* **控制診斷和統計資料**：你可以隨時在「一般設定 → 隱私 → 匿名使用統計」中撤回你的同意。關閉該選項後，程式將停止傳送任何統計資料，並同時刪除你裝置上的匿名識別碼。

* **行使其他資料權利**：對於已經傳送至伺服器的意見回饋或錯誤記錄資料，在適用法律允許的範圍內，你可以透過聯絡信箱（*
  *ivan@hanloth.com**）提出查閱、複製、更正或刪除的請求。由於本程式不建立帳號，處理此類請求通常需要你提供回饋送出時間、內容摘要等資訊以便我們定位紀錄。

### 有關我們隱私做法的其他重要資訊

**未成年人隱私**
本程式不主動面向未成年人提供服務，也不有意收集未成年人的資料。本程式不設帳號體系，不收集年齡資訊。如果未成年人在未取得監護人同意的情況下送出了相關資訊，監護人可透過聯絡信箱通知我們進行刪除。

**資料的儲存與保留**
本程式的網路資料儲存於部署在中華人民共和國境內的 Verhub 伺服器上。你的本機資料將一直保留至你自行刪除為止。伺服器端的意見回饋和錯誤記錄資料通常自送出之日起保留
12 個月（具體以 Verhub 隱私權政策為準）。

**第三方產品與服務說明**

* 如果你透過 **Microsoft Store** 取得本程式，Microsoft
  對安裝、更新與商店帳戶相關資料的處理適用 [Microsoft 隱私權聲明](https://www.microsoft.com/privacy/privacystatement)
  。本程式本身不讀取你的 Microsoft 帳戶資訊。

* 本程式的設定介面基於 Windows 內建的 **Microsoft Edge WebView2** 元件繪製，其資料處理同樣適用 Microsoft
  的相關聲明。本程式僅用該元件繪製本機介面，不載入外部網頁。
