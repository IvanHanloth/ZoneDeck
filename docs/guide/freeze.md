# 进程冻结

**进程冻结** 是隐藏窗口后的一项增强功能：在隐藏窗口的同时"挂起"对应的进程，使其停止占用 CPU（例如暂停后台视频解码、游戏渲染等）；恢复显示时自动解冻。

相关设置位于配置界面的 **能效控制** 标签页。

::: warning 进程冻结为进阶功能
冻结会让目标进程完全停止运行，其后台任务（如下载、消息接收）也会暂停。请在了解影响后再启用。

挂起只是让进程的线程不再被调度，它本身不会降低内存占用。想同时降低内存占用，见下文的[降低内存占用](#降低内存占用)。
:::

## 隐藏窗口时冻结进程

这是冻结功能的**总开关**。开启后，每次隐藏命中的窗口时，ZoneDeck 会挂起对应进程；恢复显示时自动解冻，默认使用普通冻结，**无需管理员权限**即可对当前用户的进程生效。

挂起与解冻本身需要时间，开启后可能会带来一定的隐藏 / 恢复延迟。

## 使用增强冻结

普通冻结对某些复杂程序（多进程架构、有渲染子进程等）可能不够彻底。**增强冻结**改用微软官方的 `pssuspend64.exe` 工具来挂起进程，效果更强。

启用增强冻结需要**同时满足**以下前置条件，否则该选项会被置灰：

1. 已开启"隐藏窗口时冻结进程"总开关；
2. **核心以管理员身份运行**（见下文与 [通用设置](/guide/options#核心运行权限)）；
3. 程序目录下存在 **`pssuspend64.exe`** 文件。

### 如何获取 pssuspend64.exe

1. 访问微软 Sysinternals 的 [PSTools 下载页](https://download.sysinternals.com/files/PSTools.zip)。
2. 解压下载得到的 `PSTools.zip`。
3. 从中找到 **`pssuspend64.exe`**，复制到 ZoneDeck 的**程序安装根目录**。
4. 回到配置界面，点击「进程冻结」区域的 **重新检测** 按钮，让 ZoneDeck 识别到该文件。

增强冻结需调用外部程序，同样会带来一定的隐藏 / 恢复延迟。

## 作用范围

**作用范围**决定冻结与[降低内存占用](#降低内存占用)覆盖到哪些进程。默认只管命中窗口所属的进程本身。

| 取值             | 覆盖               | 适合                              |
|----------------|------------------|---------------------------------|
| **仅目标进程**      | 命中窗口所属的进程        | 默认。单进程程序，或只想动主进程                |
| **目标进程及所有子进程** | 上者 ∪ 它的全部后代      | 浏览器、Electron 应用这类有渲染 / 辅助子进程的程序 |
| **同一程序的所有实例**  | 系统里所有**同映像名**的进程 | 多开的同一个程序                        |

::: tip 「同一程序的所有实例」按文件名匹配
「同一程序的所有实例」识别的是映像名（如 `chrome.exe`），不看进程之间的亲缘关系，也不区分安装目录——两个不同位置的同名程序会被一起纳入。它**不含**不同名的子进程。
:::

::: warning
范围越大效果越彻底，也越可能影响到你没打算动的后台任务，并带来更高的隐藏 / 恢复延迟。「目标进程及所有子进程」即为v3.2.0版本前的“冻结完整进程”功能。
:::

::: danger 别冻结文件资源管理器
`explorer.exe` 就是桌面与任务栏本身，冻结它会让整个 Windows 外壳卡住。而且 ZoneDeck 通常由它启动、是它的子进程——用「目标进程及所有子进程」冻结资源管理器会把 ZoneDeck 一起挂起。

因此 ZoneDeck 的核心与配置程序被**内置**在[白名单](/guide/whitelist#内置条目-zonedeck-自己)里，恒不冻结、不可关闭；`explorer.exe` 也预置了一条可删除的白名单条目。
:::

## 排除特定程序

不想冻结某个程序时，把它加进[白名单](/guide/whitelist)并勾上「忽略冻结」即可，不必关掉总开关。

## 降低内存占用

冻结本身不省内存。开启 **降低内存占用** 后，ZoneDeck 会在冻结成功之后**清空该进程的工作集**，把它驻留在物理内存里的数据换出到页面文件，任务管理器的"内存"一列会立刻回落。

::: warning
该选项仍在测试阶段。**可能延长恢复所需时间，但能一定程度上节省内存**——恢复时这些数据要从页面文件读回来，进程越大、机械硬盘越慢，卡顿越明显。请在了解影响后再启用。
:::

- 默认**关闭**，且需要先开启"隐藏窗口时冻结进程"，否则该选项置灰。
- 只对**被冻结的**进程生效，覆盖范围与冻结一致（见[作用范围](#作用范围)）。还在运行的进程会立刻把数据读回来，清了也白清。
- 省下的内存有一部分并不是直接被回收的：清出去的数据会先进入系统的备用列表，本来在内存吃紧时系统也会自己回收。

| 功能 | 需要管理员 | 需要 pssuspend64.exe |
| --- | :---: | :---: |
| 隐藏窗口时冻结进程 | ❌ | ❌ |
| 使用增强冻结 | ✅ | ✅ |
| 作用范围 | 取决于所配合的冻结方式 | 取决于所配合的冻结方式 |
| 降低内存占用 | ❌ | ❌ |

## 崩溃安全

ZoneDeck 会把当前冻结了哪些进程记录到 `recovery.json`。即使核心异常退出，重启后也会**自动解冻**先前被挂起的进程。

前往 [窗口恢复与崩溃自愈](/guide/recovery) 了解如何手动恢复被冻结的进程。
