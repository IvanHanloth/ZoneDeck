# 其他选项

配置界面的 **其他选项** 标签页集中了隐藏行为的增强开关、启动权限、日志与工具。本页介绍其中的常规选项、运行权限与日志。进程冻结功能请查看[进程冻结](/guide/freeze)， 窗口恢复工具请查看[窗口恢复与崩溃自愈](/guide/recovery)。

![ZoneDeck 其他选项页](/static/screenshot-4.png)

## 常规

### 隐藏窗口后静音

隐藏窗口时**静音目标进程的音频**，恢复显示时自动取消静音。适合在隐藏正在播放声音的视频 / 音乐窗口时。

- 默认**开启**。
- 基于 Windows Core Audio 会话级静音，仅静音目标进程，不影响系统其他声音。

### 同时隐藏当前活动窗口

开启后，按下隐藏热键时，除已绑定的窗口外，还会**同时隐藏当前正在激活的前台窗口**。

- 默认**开启**。
- 适合"临时正在看的窗口没有提前绑定"的场景。

### 单击托盘图标切换隐藏

开启后，**左键单击托盘图标**即可隐藏 / 显示窗口。

- 默认**开启**。

### 同时隐藏 ZoneDeck 托盘图标

开启后，隐藏窗口时会**连 ZoneDeck 自身的托盘图标一起隐藏**，更加隐蔽；再次触发恢复即可恢复窗口与图标。

- 默认**关闭**。
- 该选项只作用于 ZoneDeck 自己的托盘图标，**不会隐藏其他程序的托盘图标**（包括被隐藏窗口所属程序的图标）。

::: warning 
托盘图标被隐藏后，你将无法通过点击图标来恢复或打开设置。请务必记住你的**隐藏 / 显示热键**或鼠标手势，用它来恢复。
:::

::: tip 隐藏其他程序的托盘图标
Windows 自带控制托盘图标显隐的功能，可手动设置哪些程序的图标显示在任务栏角落，具体步骤参见微软官方教程 [在 Windows 中自定义任务栏 · 系统托盘](https://support.microsoft.com/zh-cn/windows/experience/personalization/customize-the-taskbar-in-windows#system-tray)，或直接打开 [任务栏设置](ms-settings:taskbar)（`ms-settings:taskbar` 链接仅在 Windows 上有效，浏览器会先请求确认）。
:::

### 隐藏前发送暂停键

开启后，隐藏窗口**前**会先向窗口发送**媒体暂停键**，尝试暂停其中正在播放的视频 / 音乐。

- 默认**关闭**。
- 与"隐藏后静音"侧重点不同：静音只是消音，暂停键会真正暂停播放。
- 除了此功能外，ZoneDeck 提供的**进程冻结**功能，也有相同的暂停效果，同时还能降低资源消耗，详见 [进程冻结](/guide/freeze)。

## 启动与权限

### 开机自启

切换 ZoneDeck 是否随系统登录自动启动核心。详细机制见 [开机自启](/guide/autostart)。

### 核心运行权限

显示当前核心的运行状态（未运行 / 普通用户 / 管理员），并提供**以管理员身份启动 / 重启核心**的按钮。

以下功能需要核心以管理员身份运行：

- [增强冻结](/guide/freeze#使用增强冻结)；
- [计划任务最高权限自启](/guide/autostart)。

## 语言

### 界面语言

设置配置界面与核心的托盘菜单、气泡通知所使用的语言。

可选值：**跟随系统 / 简体中文 / English / 繁體中文**，默认 **跟随系统**。

- 选择"跟随系统"时，按 Windows 的显示语言决定：中文（台湾 / 香港 / 澳门）显示繁体中文，其他中文显示简体中文，英文显示英文，其余语言回落到简体中文。
- 改动即时生效，配置界面与核心同时切换，无需重启。
- 运行日志不受该设置影响，始终使用简体中文记录。

## 日志

### 日志保留天数

核心运行日志按天保存在**程序目录的 `logs` 文件夹**内，核心启动时会自动清理更早的日志。

可选值：**关闭 / 3 天 / 7 天 / 14 天 / 30 天**，默认 **7 天**。选择"关闭"则完全不记录日志。

### 日志输出等级

只记录所选等级**及以上**的日志。可选值：**调试 / 信息 / 警告 / 错误**，默认 **警告**。

| 等级 | 记录范围 |
| --- | --- |
| 调试 | 全部内容，含每次隐藏 / 恢复的明细、热键注册结果等流水 |
| 信息 | 上述流水之外的运行里程碑，如更新后首次启动 |
| 警告（默认） | 只记警告与错误：热键注册失败、规则未匹配到窗口、检测到上次异常退出等 |
| 错误 | 只记错误：核心无法启动、配置解析失败、崩溃信息等 |

默认的"警告"下，日常的隐藏与恢复**不会写进日志**，日志文件只留下真正需要关注的内容。反馈问题前可临时调低到"调试"，复现一次问题后再调回来。选择"关闭日志保留天数"时该项不可用。

无论选哪一级，每次启动与正常退出都会各记一行会话标记，其中含版本号与数据目录，便于定位问题。

::: tip 排查问题先看日志
当程序出现异常时，`logs` 文件夹中的日志是定位问题的第一手资料。反馈问题时附上相关日志能大幅提高排查效率。相关内容另见 [窗口恢复与崩溃自愈](/guide/recovery)。
:::

## 工具

### 窗口恢复工具

用于**找回被误隐藏、无法通过热键恢复的窗口**。点击"打开"后会列出所有窗口，勾选后即可恢复显示。详见 [窗口恢复与崩溃自愈](/guide/recovery#窗口恢复工具)。
