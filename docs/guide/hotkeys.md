# 热键与鼠标手势

ZoneDeck 提供多种触发隐藏 / 恢复的方式：键盘全局热键、鼠标按键连击、快速移动到屏幕四角，以及空闲自动隐藏。它们都在配置界面的 **热键与鼠标** 标签页中设置。

![ZoneDeck 热键与鼠标设置页](/static/screenshot-2.png)

::: tip 编辑时自动暂停监听
当鼠标进入"热键与鼠标"设置区域时，核心会**临时暂停**热键与鼠标监控，避免你在录制 / 调试时误触发隐藏。离开该区域或窗口失焦后自动恢复。可在窗口右下角看到热键监控状态
:::

## 键盘热键

包含五个可自定义的全局热键：

| 功能 | 默认值 | 说明 |
| --- | --- | --- |
| **隐藏 / 显示窗口** | `Ctrl + Q` | 已隐藏时恢复，未隐藏时隐藏 |
| **仅隐藏窗口** | 已关闭 | 只隐藏，不恢复 |
| **仅显示窗口** | 已关闭 | 只恢复，不隐藏 |
| **隐藏前台窗口** | 已关闭 | 只隐藏当前活动的那一个窗口 |
| **关闭核心** | `Win + Esc` | 退出核心（退出前会恢复所有窗口） |

点击 **录制** 按钮，输入框提示"请按下组合键…"后按下想要的组合键，程序会自动识别并填入。

点击 **清除** 按钮可置空该热键。置空后该项显示为"已关闭"，核心不再注册它，对应功能无法通过键盘触发；五个热键相互独立，可单独置空。

### 单向热键与隐藏前台窗口

后三个热键默认置空，需要时自行录制：

- **仅隐藏窗口**：按规则隐藏，但绝不恢复。适合把隐藏与恢复拆成两个键，避免误按同一个键把刚藏好的窗口又放出来。
- **仅显示窗口**：只恢复已隐藏的窗口，绝不触发隐藏。
- **隐藏前台窗口**：**不套用**[窗口 / 进程规则](/guide/binding)，只隐藏当前活动的那一个窗口。可连续按下，每按一次多藏一个窗口。

隐藏是**累加**的：无论用哪种方式隐藏，被隐藏的窗口都会记在同一份清单里，恢复时一并放出。因此上述三个热键隐藏的窗口，只能通过 **仅显示窗口**、**隐藏 / 显示窗口**（此时它执行恢复），或托盘菜单、鼠标手势等其他恢复方式放出来。

::: tip
**隐藏前台窗口** 隐藏的是当前获得焦点的普通顶层窗口。若焦点不在这类窗口上（例如停在桌面或某些工具窗口），该次触发不做任何事，并在日志中留下记录。
:::

### 热键不传递

每个热键各配有一个独立的 **不传递** 开关（默认关闭），位于该热键所在行的右端。开启后，触发该热键时按键的按下与抬起都不会传给前台程序，避免游戏、聊天输入框等误收按键。

::: info 关于全局热键
ZoneDeck 默认使用系统的 `RegisterHotKey` 注册全局热键。若某个组合键已被其他程序占用，注册可能失败，请换一个组合键。

开启「不传递」的热键改用底层键盘钩子（`WH_KEYBOARD_LL`）拦截，不再走 `RegisterHotKey`，因此不受组合键占用冲突的影响；若键盘钩子安装失败，该热键会回退为普通注册，仍可触发功能，只是无法阻止按键传递。少数直接读取 Raw Input 的程序不经过键盘钩子，仍可能观察到按键。
:::

## 鼠标按键隐藏

除了键盘，你还可以用鼠标按键触发隐藏。支持五颗鼠标键：**左键、中键、右键、侧键 1（前进）、侧键 2（后退）**。

默认开启 **鼠标中键双击隐藏**，并允许"再按一次恢复"。

每颗启用的按键都可独立配置：

- **连击次数**：单击、双击或三连击才触发。
- **修饰键**：可要求同时按住 `Ctrl` / `Shift` / `Alt` / `Win` 组合，例如"按住 Ctrl 时中键双击"才隐藏。留空表示不需要修饰键。

此外有两个全局选项（对五颗键共同生效）：

- **按键恢复**：开启后，再按一次同样的键即可恢复已隐藏的窗口。
- **连击判定窗口**：多次点击间隔不超过该时长（毫秒）才算作连击，默认 **350 毫秒**。

::: warning
配置**左键 / 右键**触发时请务必搭配连击或修饰键，否则会干扰正常点击操作。
:::

## 移动到屏幕四角隐藏

![ZoneDeck 鼠标按键与四角设置](/static/screenshot-3.png)

启用后，把鼠标**移动到屏幕的某个角落**即可触发隐藏 / 恢复。你可以分别开启四个角（左上、右上、左下、右下）。

配套选项：

- **仅快速移动触发**（默认开启）：只有**快速**把鼠标移到角落才触发，避免正常操作误触；关闭后只要移动到角落就触发。
- **角落恢复**：开启后，允许通过移动鼠标到角落来**恢复**已隐藏的窗口（默认只能通过此方式隐藏而不支持恢复）。

::: info
四角隐藏依赖底层鼠标钩子（`WH_MOUSE_LL`），仅在你启用了鼠标按键或四角功能时才会安装。如果你完全不使用鼠标触发，核心不会安装该钩子。
:::

## 空闲自动隐藏

开启 **启用自动隐藏** 后，当键盘和鼠标在设定时长内**无任何操作**时，ZoneDeck 会自动隐藏已绑定的窗口——适合临时离开工位的场景。

- **空闲时长**：无操作达到该时长（分钟）后触发，默认 **5 分钟**。
- **托盘菜单快速切换**：右键托盘图标，点击 **自动隐藏** 菜单项即可暂停 / 启用自动隐藏，无需打开设置界面；勾选标记表示当前已启用，切换结果与设置界面保持同步。托盘图标还可叠加角标显示该状态，见[图标状态提示](/guide/notifications#图标状态提示)。

## 小结

| 触发方式 | 适用场景 |
| --- | --- |
| 键盘热键 | 最通用、最快捷 |
| 鼠标连击 / 侧键 | 手在鼠标上时更顺手 |
| 屏幕四角 | 无需记忆按键，甩一下即可 |
| 空闲自动隐藏 | 临时离开、忘记手动隐藏时的兜底 |

配置好触发方式后，你可能还想调整隐藏时的附加行为（静音、暂停、冻结等），请见 [其他选项](/guide/options) 与 [进程冻结](/guide/freeze)。
