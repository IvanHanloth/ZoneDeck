# 开机自启

开启开机自启后，ZoneDeck 核心会**随系统登录自动在后台启动**，你无需每次手动运行。

## 如何开启 / 关闭

有两种入口，效果一致：

1. **托盘菜单**：右键点击托盘图标 → 选择 **"开机自启"** 切换状态。
2. **配置界面**：**其他选项 → 启动与权限 → 开机自启** 开关。

切换后（若未关闭对应通知）会弹出气泡提示当前的自启状态。开关旁的小字会标注当前的注册方式（**计划任务** 或 **注册表**）。

## 自启机制

ZoneDeck 采用**双保险**的自启方式，兼顾权限与可靠性：

| 机制 | 说明 |
| --- | --- |
| **计划任务（首选）** | 以"登录触发"的计划任务注册，可请求**最高权限**运行，并带有**失败自动重启** 能力 |
| **注册表启动** | 当计划任务不可用时，将使用普通注册表启动项 |

配置界面「其他选项 → 启动与权限 → 开机自启」开关旁会用小字显示当前实际生效的方式，便于你确认计划任务是否成功注册（未成功时会回退到注册表）。

## 关于"最高权限自启"

若你希望核心在开机时就**以管理员身份**启动（例如为了 [增强冻结](/guide/freeze#使用增强冻结)），打开 **启动与权限 → 开机时以管理员身份启动** 开关即可——它会以最高权限的计划任务方式注册自启。

- 该开关**默认关闭**，即普通权限自启，满足绝大多数场景。
- 开关**仅在计划任务方式下生效**；若自启回退到了注册表方式，则只能以普通权限启动。
- 在自启已开启时切换该开关，会立即按新权限**重新注册**，无需手动关闭再打开。

::: warning 卸载 / 迁移前请先关闭自启
如果你要删除便携版目录或移动程序位置，请**先在托盘菜单关闭开机自启**，以免残留一个指向旧路径的失效自启项。
:::
