# Boss Key 使用文档

**Boss Key（老板键）** 是一款面向 Windows 平台的「摸鱼」辅助工具：当你需要快速隐藏正在使用的窗口时，只需按下一个热键、点一下鼠标，或把鼠标甩到屏幕角落，即可一键隐藏并静音指定窗口；老板走后再触发一次即可恢复。

![Boss Key 配置界面 - 窗口绑定页](/static/screenshot-1.png)

## 主要特性

- **多窗口 / 多进程隐藏**：可同时隐藏任意数量的窗口，或按进程隐藏某个程序的全部窗口。
- **多种触发方式**：键盘全局热键、鼠标中键 / 侧键连击（可搭配修饰键）、快速移动到屏幕四角、空闲自动隐藏。
- **隐藏增强**：隐藏后自动静音、发送媒体暂停键、冻结进程以降低 CPU / 内存占用、连托盘图标一起隐藏。
- **精细匹配**：既能锁定单个窗口，也能用**正则表达式**批量匹配标题或进程路径。
- **极低占用**：v3 使用 Rust 重写，核心常驻仅约 350 KB 二进制、约 1 MB 内存。
- **稳定可靠**：崩溃日志、崩溃恢复、看门狗三层防线，避免窗口"永久消失"。
- **现代配置界面**：无边框窗口、亮 / 暗 / 跟随系统主题、配置自动保存、内置检查更新与反馈上报。

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 及以上（部分版本另提供 Windows 7 软件包） |
| 运行时依赖 | 配置界面依赖系统自带的 Microsoft Edge **WebView2**（Win10/11 通常已内置） |
| 权限 | 默认普通用户权限即可运行；仅**增强冻结**与**计划任务最高权限自启**需要管理员 |

## 版本说明

::: info v3 全新重构
从 **v3.0.0** 开始，Boss Key 使用 **Rust + Tauri** 全面重写，相较于早期的 Python 版本大幅降低了内存占用、提升了稳定性，并采用了全新的视觉设计。本使用文档以 v3 为准。
:::
