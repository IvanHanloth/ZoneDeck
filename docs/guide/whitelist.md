# 白名单

你可以为ZoneDeck配置进程白名单，使其对特定进程的窗口跳过特定步骤。

隐藏窗口时，ZoneDeck 可能对目标做三件事——隐藏窗口、冻结进程、静音音频。白名单让你逐个程序、逐项关掉其中任意一件，其余照旧。

打开配置界面，切换到 **白名单** 标签页。界面与[窗口绑定](/guide/binding)同构：左栏是现有窗口，右栏是白名单条目。

## 三种忽略模式

每条白名单条目上有三个独立开关，互不影响：

| 开关 | 作用                          |
| --- |-----------------------------|
| **忽略隐藏** | 隐藏时跳过这个程序的窗口，它始终留在桌面上       |
| **忽略冻结** | 不[冻结](/guide/freeze)它的进程，后台任务继续跑 |
| **忽略静音** | 不静音这个程序                       |

三个开关**相互独立**。冻结与静音是否触发是根据「这个程序还有没有窗口留在桌面上」——窗口开着就都不会施加，而它自己缩到托盘后照样会被冻结、静音。

## 添加条目

1. 在左侧"现有窗口"列表中**勾选**目标窗口。
2. 点击右侧的 **添加进程** 按钮。
3. 在新增的那一行上勾选需要的忽略模式（新条目默认三个都不勾，等同于没有效果）。

## 匹配依据

与[进程隐藏规则](/guide/binding#进程正则规则)一样，每条条目可以选择按**文件名**或按**路径**匹配：

- **文件名**（默认）：只看 `xxx.exe`，程序装在哪个目录都算命中。白名单默认按文件名匹配——换个安装目录就失效的保护形同虚设。
- **路径**：只放过指定位置的那一个程序，同名的其他副本不受影响。

点击 **正则** 按钮可以添加正则条目，正则作用于文件名还是完整路径同样由「匹配依据」决定。

::: tip
文件名与路径的比较都**不区分大小写**：`Explorer.EXE` 与 `explorer.exe` 是同一个目标。
:::

## 默认条目：文件资源管理器

全新安装时，白名单里预置了一条 `explorer.exe`，勾选了**忽略隐藏**与**忽略冻结**。

文件资源管理器就是桌面与任务栏本身：隐藏它会让桌面图标一并消失，冻结它会让整个 Windows 外壳卡住。这条是普通条目，你可以修改或删除它。

## 内置条目：ZoneDeck 自己

列表最上方有两条带锁的条目，**不能修改也不能删除**：

| 条目 | 覆盖的映像名 |
| --- | --- |
| ZoneDeck 核心 | `ZoneDeck.exe`、`core.exe` |
| ZoneDeck 设置 | `config.exe`、`zonedeck-config.exe` |

它们恒定处于「忽略冻结」状态。原因是这样的：核心通常由资源管理器启动，因而是 `explorer.exe` 的子进程；配置程序又是核心的子进程。一旦你把[作用范围](/guide/freeze#作用范围)设成「目标进程及所有子进程」去冻结资源管理器，整棵进程树连 ZoneDeck 一起被挂起——热键不再响应，配置界面打不开，已经隐藏的窗口**再也无法恢复**。

[窗口恢复工具](/guide/recovery)里的手动冻结同样受它保护。

## 与隐藏规则的关系

白名单的优先级**高于**[窗口绑定](/guide/binding)里的任何规则。一个程序既被进程隐藏规则命中、又在白名单里勾了「忽略隐藏」时，白名单说了算——规则不必删掉，临时不想让它参与隐藏，勾一下白名单即可。
