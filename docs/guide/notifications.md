# 提示设置

ZoneDeck 通过**系统通知**与**托盘图标角标**两类提示反映核心状态。在配置界面的 **通用设置** 标签页，你可以决定托盘图标是否显示、点击它做什么，以及各类通知与角标的行为，做到既知情又不打扰。

## 显示托盘图标

托盘图标默认显示在通知区域。关闭该选项后图标彻底消失，更隐蔽。

- 默认**开启**。
- 图标关掉后，图标上的点击行为、悬浮名称与状态角标随之失效，配置界面里对应的设置项会置灰。**通知不受影响**，照常弹出。
- **同时隐藏 ZoneDeck 托盘图标**（[隐藏设置](/guide/hiding#同时隐藏-zonedeck-托盘图标)）是隐藏窗口时的联动，与本项相互独立。
- 该开关改完立即生效，不必重启核心。

::: warning 关掉之前先想好怎么找回来
没有图标就点不到菜单。此时仍可**再次运行 ZoneDeck**（双击程序或快捷方式）打开配置界面 —— 核心已在运行时，重复启动会转为打开设置。但恢复窗口只能靠你的**隐藏 / 显示热键**或鼠标手势，请务必先记住它。
:::

## 托盘图标点击行为

托盘图标的**左键单击**、**左键双击**、**右键单击**各自绑定一个动作，可选：

| 动作 | 说明 |
| --- | --- |
| **无操作** | 什么都不做 |
| **隐藏 / 显示窗口** | 切换隐藏状态，等同按一次隐藏 / 显示热键 |
| **显示托盘菜单** | 弹出[托盘菜单](/guide/getting-started#托盘菜单) |
| **打开配置界面** | 打开本设置窗口 |

默认绑定：

| 点击 | 默认动作 |
| --- | --- |
| 左键单击 | 隐藏 / 显示窗口 |
| 左键双击 | 无操作 |
| 右键单击 | 显示托盘菜单 |

::: tip 双击一旦绑上，单击就会慢半拍
系统无法在第一次点击时就断定后面还有没有第二下。因此只要双击绑了动作，单击就必须等过系统的双击判定时间（可在 Windows 鼠标设置里调整）才能执行。双击保持「无操作」时没有这个冲突，单击立即响应。
:::

## 可控制的通知事件

| 事件 | 说明 | 默认 |
| --- | --- | :---: |
| **核心启动** | 核心开始运行时提示 | 开启 |
| **核心退出** | 核心退出时提示 | 开启 |
| **开机自启状态变更** | 切换开机自启时提示当前状态 | 开启 |
| **隐藏窗口** | 每次隐藏窗口时提示 | 关闭 |
| **显示窗口** | 每次显示窗口时提示 | 关闭 |

## 图标状态提示

托盘图标可在**右下角叠加一个彩色圆点角标**，直观反映核心当前状态。四种颜色各自绑定一个状态源，默认绑定如下：

| 颜色 | 默认绑定状态 |
| --- | --- |
| 红色 | 存在隐藏中的窗口 |
| 绿色 | 启用了自动隐藏 |
| 黄色 | 启用了同时隐藏当前窗口 |
| 蓝色 | 启用了进程冻结 |

- 每种颜色都可以改绑为其他状态（除上表四种外，还可绑定**以管理员身份运行**、**热键监控已暂停**），或选择「不显示」置空该颜色。
- 多个绑定状态同时满足时，按 **红 > 绿 > 黄 > 蓝** 的优先级只显示一个圆点。

::: warning 隐蔽性提示
角标（尤其是「存在隐藏中的窗口」）也会向旁人透露核心状态。若你更在意隐蔽性，可将相应颜色置空。
:::

## 显示图标悬浮名称

鼠标悬停在托盘图标上时默认显示「ZoneDeck」。关闭该选项后，悬停不显示任何文字，更隐蔽。

- 默认**开启**。

## 使用建议

- **隐藏 / 显示通知默认关闭**：隐藏本身就是为了保护隐私，每次隐藏都弹通知反而会引起注意，因此默认不提示。若你希望有明确反馈可自行开启。
- **启动 / 退出 / 自启通知默认开启**：这些是低频事件，保留提示有助于你确认核心状态。

::: info 与"隐藏 ZoneDeck 托盘图标"的区别
[同时隐藏 ZoneDeck 托盘图标](/guide/hiding#同时隐藏-zonedeck-托盘图标) 是**隐藏窗口时**的联动，触发恢复会恢复显示；本页的「显示托盘图标」则是使托盘图标**一直不显示**。
:::
