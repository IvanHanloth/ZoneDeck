# Earlier versions

These versions predate the project's move to GitHub Releases. They have no Release record and therefore no download links; only their release notes are archived here.

## V1.4.0

<p class="release-meta">Updated 2024/10/11</p>

- Added muting after hiding a window
- Changed the default "close program" key binding
- Fixed a dialog appearing every time
- Fixed binding errors caused by launching twice
- Improved exit speed

## V1.3.0

<p class="release-meta">Updated 2023/9/17</p>

- Rewritten in an object-oriented style
- Added a settings GUI
- Added a tray icon menu
- Added a one-click installer
- Improved the overall experience
- Improved Windows 11 compatibility
- Fixed a startup registration failure
- Dropped the single-file edition

## V1.2.0

<p class="release-meta">Updated 2023/5/21</p>
